# Plan d'Optimisation SEO, Calculateur Officiel des Notes EPS (OP 2007/2009) & Grille Processus à Cocher

Ce plan détaille le fonctionnement exact du **Calculateur Officiel des Notes EPS sur 20 (OP 2009 Collège & OP 2007 Lycée)** basé sur les grilles d'évaluation de votre **Générateur**, ainsi que son maillage stratégique avec le **Calculateur VMA**, les **articles Course en durée / Course de durée** et les **13 Silos Sports**.

### Validation Utilisateur & Fonctionnement Exact du Calculateur des Notes

> [!IMPORTANT]
> **Répartition Entière Officielle de la Note Procédurale (Zéro demi-point 6,5) :**
> - **Procédurale sur 12 pts** *(1AC, 2AC, 3AC & TC en Athlétisme)* : **6 pts Performance (Produit)** + **6 pts Processus** *(+ 3 Conceptuel + 5 Comportemental = 20)*
> - **Procédurale sur 13 pts** *(1Bac en Athlétisme ; 1AC, 2AC, 3AC & TC en Gymnastique et Sports Collectifs)* :
>   - *Athlétisme & Gymnastique* : **6 pts Performance (Produit / Difficulté)** + **7 pts Processus** *(+ 3 Conceptuel + 4 Comportemental = 20)*
>   - *Sports Collectifs* : **6 pts Individuel** + **7 pts Collectif** *(+ 3 Conceptuel + 4 Comportemental = 20)*
> - **Procédurale sur 14 pts** *(1Bac en Gymnastique & Sports Collectifs ; 2Bac dans toutes les APS)* :
>   - *Athlétisme & Gymnastique* : **7 pts Performance (Produit / Difficulté)** + **7 pts Processus** *(+ 3 Conceptuel + 3 Comportemental = 20)*
>   - *Sports Collectifs* : **7 pts Individuel** + **7 pts Collectif** *(+ 3 Conceptuel + 3 Comportemental = 20)*

1. **Composante 1 — Note Procédurale (divisée en 2 sous-notes entières : Performance/Individuel + Processus/Collectif)** :
   - **A. Note de Performance / Capacité Individuelle (`/6 pts` ou `/7 pts` selon le niveau OP)** :
     - Le professeur sélectionne le **Niveau** (`1AC`, `2AC`, `3AC`, `TC`, `1Bac`, `2Bac`), le **Sexe** (`Garçons` / `Filles`) et l'**APS**.
     - La **Situation de Référence (SR)** officielle du niveau s'affiche automatiquement (ex. *Course en durée 2Bac : Courir 1000m Garçons / 600m Filles* ; *Course de vitesse : 80m Garçons / 60m Filles* ; *Lancer de poids : 3kg/4kg Filles, 4kg/5kg Garçons* ; *Saut en longueur / Hauteur* ; *Gymnastique : 3A2B à 2C3D2E*).
     - Dès que le professeur saisit la **performance chiffrée de l'élève** (temps réalisé, distance en mètres, hauteur franchie, éléments gymniques A/B/C/D/E ou capacité individuelle en sport collectif), le calculateur donne automatiquement la **Note Performance / Individuelle** sur **`/6 pts`** (pour les barèmes procéduraux à 12 et 13 pts) ou sur **`/7 pts`** (pour les barèmes procéduraux à 14 pts).
   - **B. Note de Processus / Capacité Collective (`/6 pts` ou `/7 pts` — Grille à cases à cocher issue du Générateur)** :
     - La grille reprend exactement les **4 phases / critères d'observation du Générateur** pour chaque APS, avec **2 cases à cocher par critère** (Critère maîtrisé vs Critère non maîtrisé).
     - **Pondération des 4 critères cochés** :
       - Quand le **Processus est sur 6 points** *(Procédurale = 12 pts : 6 Perf + 6 Processus)* : les 4 critères valent **1,5 pt chacun** ($4 \times 1{,}5\text{ pt} = 6\text{ pts}$).
       - Quand le **Processus (ou Collectif) est sur 7 points** *(Procédurale = 13 pts : 6 + 7, ou Procédurale = 14 pts : 7 + 7)* : les 4 critères totalisent **7 points** (**2,0 pts** pour les 2 critères fondamentaux + **1,5 pt** pour les 2 autres critères = $2 + 2 + 1{,}5 + 1{,}5 = 7\text{ pts}$).
     - Le professeur coche la case qui correspond à l'élève pour chacune des 4 colonnes (ex. `Course : [✓ Axée] [ Désaxée]`) et le calculateur **additionne automatiquement les points des critères cochés** pour afficher la **Note Processus / Collectif** sur `/6 pts` ou `/7 pts`.

2. **Composante 2 — Note Conceptuelle (Saisie libre par le professeur sur `/3 pts`)** :
   - Champ de saisie directe de `0` à `3 pts` laissé au professeur.

3. **Composante 3 — Note Comportementale (Saisie libre par le professeur sur `/5 pts`, `/4 pts` ou `/3 pts`)** :
   - Champ de saisie directe dont le barème maximal s'ajuste automatiquement au niveau OP sélectionné :
     - **`/5 pts`** quand la Note Procédurale est sur **12 pts** (`12 + 3 + 5 = 20`),
     - **`/4 pts`** quand la Note Procédurale est sur **13 pts** (`13 + 3 + 4 = 20`),
     - **`/3 pts`** quand la Note Procédurale est sur **14 pts** (`14 + 3 + 3 = 20`).

4. **Sommation Automatique & Double Mode (Fiche Élève + Grille de Classe 35 Élèves)** :
   - Le calculateur additionne en temps réel : $\text{Note Performance (ou Individuel)} + \text{Note Processus (ou Collectif)} + \text{Note Conceptuelle} + \text{Note Comportementale} = \textbf{Note Totale /20}$.
   - Disponible en **Mode Calculateur Individuel** et en **Mode Grille de Classe Interactive (35 élèves)** exportable en **Word (.doc) et PDF A4**.
