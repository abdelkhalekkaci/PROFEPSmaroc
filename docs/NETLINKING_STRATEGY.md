## Piliers de la stratégie

### 1. Contenu lienable (Linkable Assets)

Créer des ressources que les autres sites *veulent* naturellement citer :

| Ressource | Format | Cible |
|---|---|---|
| **Générateur de fiches EPS** (existant) | Outil web gratuit | Sites éducation, blogs CRMEF |
| **Bibliothèque numérique EPS** (existant) | Page répertoire | Universités, ENS, ESEF |

| **Comparatif OP 2007 vs 2009** (existant) | Article guide | Sites pédagogiques |
| **Glossaire didactique EPS** | Page lexique | Blogs éducation |

| GitHub | Code | Publier le projet open source |

### 4. Broken Link Building

1. Trouver des sites marocains qui listent des ressources éducatives avec des liens morts
2. Proposer de remplacer le lien mort par un lien vers profeps.ma (page équivalente)
3. **Outils** : Check My Links (Chrome), Ahrefs Broken Link Checker

### 5. E-mailing : Template d'approche

```
Objet : Proposition de partenariat — ProfEPS.ma

Bonjour [Prénom],

Je suis le créateur de ProfEPS.ma, plateforme gratuite dédiée aux
professeurs d'EPS au Maroc : générateur de fiches pédagogiques,
bibliothèque numérique, et articles conformes aux OP 2007-2009.

J'ai vu votre article/site [TITRE] et je pense qu'une collaboration
serait pertinente. Je vous propose :

1. Un échange de liens vers nos ressources respectives
2. Ou la rédaction d'un article invité pour votre site
3. Ou l'inclusion de votre ressource dans notre bibliothèque numérique

Consultez la plateforme : https://www.profeps.ma

Bien cordialement,
[Votre nom]
profepsma@gmail.com
```
